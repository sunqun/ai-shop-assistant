# 目标

在 memory 目录下按记录类型分文件夹，用 Markdown 维护三类持久记忆，并保持 MEMORY.md 索引与实际文件一致。

# 记录分类

| 类别 | 文件路径 | 用途 |
| --- | --- | --- |
| 决策记录 | `decision/decision_*.md` | 记录每次决策的详细信息 |
| 反馈记录 | `feedback/feedback_*.md` | 记录反复被纠正的问题 |
| 参考记录 | `reference/reference_*.md` | 记录项目可参考的文档、工具 |

# 各记录字段

- 决策记录：标题、背景、决定、否掉的方案、日期、版本号、变更点
  - 「版本号」标识当前迭代版本；「变更点」记录相对上一版的变化。
  - 「否掉的方案」记录相对上一版决策的更改；首次决策（无上一版）不需要生成。
- 反馈记录：问题、纠正方式
- 参考记录：名称、说明

# 读写规则

- 文件名采用语义化命名。
- 新增记录时，在对应类型文件夹下创建 Markdown 文件，并填充该类型的全部字段。
- 新增记录后，同步在 `MEMORY.md` 追加索引行，格式为 `类别-文件路径-描述`，例如 `决策记录-decision/decision_authorization.md-记录了授权设计`。
- 删除记录时，同步移除 `MEMORY.md` 中对应的索引行。
- 决策记录同一文件内最多保留 3 版迭代，超过 3 版时默认删除最旧的一版。
- 查询历史约定或决策时，先读 `MEMORY.md` 定位，再按需读取对应记录文件。
