# 支付短链区域布局用例

## 覆盖范围

验证首页已保存支付短链与 AI 助手面板的相对位置，以及空状态下区域隐藏行为。

## 用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| PL-LAYOUT-01 | 用户有有效短链 | 登录后打开首页 | 支付短链区域独立显示在 AI 助手面板上方；复制、打开和删除操作可用 |
| PL-LAYOUT-02 | 用户没有有效短链 | 登录后打开首页，或删除最后一条短链 | 支付短链区域隐藏，助手面板占据右侧栏空间 |
| PL-LAYOUT-03 | 短链数量较多 | 创建多条短链并打开首页 | 短链区域限制高度并在区域内部滚动；助手面板仍可使用且不被遮挡 |
