# 语言切换测试用例

范围：全局页头语言选择器、页面文案、`<html lang>` 和浏览器本地持久化。

| 编号    | 场景         | 操作                                                      | 预期结果                                                                          |
| ------- | ------------ | --------------------------------------------------------- | --------------------------------------------------------------------------------- |
| LANG-01 | 默认语言     | 清除 `ai-shop-locale` 后打开首页                          | 页面以繁體中文显示，选择器显示“繁體中文”，`html[lang]` 为 `zh-TW`                 |
| LANG-02 | 切换简体中文 | 选择“简体中文”，打开商品、购物车和我的页面                | 共享导航、页面标题、按钮、占位说明和助手面板显示简体中文，`html[lang]` 为 `zh-CN` |
| LANG-03 | 切换英文     | 选择 English，打开商品详情和订单相关页面                  | 页面主要可见文案显示英文，动态商品/订单标识保留且前缀翻译，`html[lang]` 为 `en`   |
| LANG-04 | 刷新持久化   | 在英文状态刷新页面                                        | 仍为英文，不回退到默认语言                                                        |
| LANG-05 | 非法存储值   | 将 `ai-shop-locale` 改为任意非法值后刷新                  | 回退到繁體中文，不抛出客户端错误                                                  |
| LANG-06 | 键盘与布局   | 使用键盘聚焦语言选择器并切换，检查桌面宽度 1024/1280/1440 | 选择器可操作，页头无横向溢出，主要内容不被语言控件遮挡                            |

执行记录：`npm run typecheck`、`npm run build` 已通过；浏览器交互用例在本次环境中需启动开发服务器后执行。
