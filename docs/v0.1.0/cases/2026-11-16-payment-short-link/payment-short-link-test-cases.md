# 支付短链测试用例

## 范围

覆盖 AI 助手生成、保存、删除支付短链，以及匿名访问短链并输入支付密码后下单的主流程与失败路径。

## 用例

| 编号 | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| PL-01 | 未登录生成 | 在商品卡点击“生成支付短链” | 打开现有登录弹窗；登录成功后自动继续生成并显示短链 |
| PL-02 | 登录用户生成 | 选择数量后点击生成 | 短链绑定当前登录用户、商品和数量，助手顶部出现短链区域 |
| PL-03 | 持久化 | 刷新页面并保持登录 | 已生成短链仍显示；短链地址可复制和打开 |
| PL-04 | 删除 | 点击短链的“删除” | 服务端软删除，列表立即移除，原地址返回不可用 |
| PL-05 | 匿名访问 | 在未登录浏览器打开短链 | 能读取创建者用户名、商品和数量，不弹登录框 |
| PL-06 | 支付密码门槛 | 不输入支付密码直接提交 | 页面阻止提交；服务端拒绝请求 |
| PL-07 | 短链下单 | 输入任意非空支付密码后提交 | 使用创建者身份执行 AI 购物车、报价、订单和库存逻辑，显示订单回执 |
| PL-08 | 无效 token | 修改 URL token 后访问 | 返回“支付短链不可用”，不创建订单 |
| PL-09 | 库存不足 | 短链商品无可用库存时提交 | 返回库存不足提示，不创建订单 |
| PL-10 | 越权删除 | 使用其他用户的 linkId 调用删除接口 | 返回不存在或不可用，不影响原短链 |
| PL-11 | 成功下单后失效 | 输入支付密码并成功下单，再访问原短链 | 原短链立即不可用，助手短链列表不再显示该链接，不能重复下单 |
