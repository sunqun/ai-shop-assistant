# 需求功能清单：通用商品检索意图

日期：2026-11-20。范围：直接实施通用意图抽象；保留现有桌面商城和购物任务流程。

| 功能 | 实施要求 |
| --- | --- |
| 商品主体 | 模型提取商品类型、品类、品牌，别名仍使用目录别名表；不逐句维护用户问法 |
| 必需条件 | 任意自然语言条件，不再使用 fast_charge 等功能枚举 |
| 数值条件 | 任意规格属性名、gte/lte/eq 比较、数值、单位；不再使用 capacityMah/outputWatts 等字段枚举 |
| 偏好 | 任意场景或主观偏好，独立于硬过滤，不猜测数值门槛 |
| 排除 | 保留现有排除商品、品牌、品类及预算、评分、库存条件 |
| 证据校验 | 目录描述与规格直接匹配，无法直接匹配时进行只读语义评估；证据必须是目录原文 |
| 不确定性 | 未知条件和未核实数值展示候选并追问，不能自动加购或下单 |
| 兼容性 | 保留旧 specTerms 输入，在归一化时转换；页面不重做布局 |

验收：充电宝原例可召回；20000mAh 下限不可返回 10000mAh；重量、长度、时长、容积等共用比较器；不同单位可换算；否定、缺规格、模型故障、虚构引用和多轮条件均有测试。

限制：本次未建立向量索引，不宣称可理解任意输入；商品主体召回仍依赖目录词与运营别名。语义模型不能核实的条件必须澄清。偏好暂不改变现有目录排序。

支付、费用、授权、库存与订单规则未新增；如需改变，标记 `needs_human_review`，不得借意图抽象自行调整。
