# 需求功能清单

## 目标

支持用户用自然语言请求购物助手完成“查找商品、按目录推荐顺序选择有货商品、加入购物车、报价，并在用户明确确认且已授权时创建订单”。

## 功能

- 接收商品搜索与购买意图。
- ReAct 循环调用商品目录、推荐商品选择、AI 购物车、报价和订单工具。
- 只使用工具返回的商品、库存、价格、报价和订单数据。
- 推荐选择规则：从本次搜索结果中选择目录排序靠前的有库存商品；推荐排序分数及其内部计算规则不进入 Agent 上下文或用户界面。
- 下单前保留确认状态；未确认时返回待确认结果。
- 下单接口沿用登录、AI 下单授权、库存、报价过期和幂等校验。

## needs_human_review

- 是否允许助手在用户确认后直接创建订单，支付是否必须继续跳转人工支付流程。
- 多规格商品、优惠叠加、配送地址和缺货替代规则。
