# 需求功能清单

更新日期：2026-11-21。范围：当前工作区的桌面浏览器商城、内置 AI 搜索助手与 AI 购物对话页。

本文描述现有功能与边界，不保留问题修复过程和历史审查结论。功能状态依据代码，不能替代运行验收；未确认的业务规则统一标为 needs_human_review。

相关文档：[前端交互与技术文档](frontend-technical.md)、[后端技术文档](backend-technical.md)。

## 1. 产品范围

- 用户可浏览商品、查看详情和评论、维护普通购物车、获取报价、创建订单记录并查询本人订单。
- 首页右侧为商品搜索助手；/assistant 为单一自动购物对话页：商品无差异时自动下单，有差异时展示差异与报价并等待用户接受。
- AI 购物任务目前处理一个商品主体及明确件数；普通购物车支持多个商品。AI 件数为 1–99，未指定时使用当前服务端默认值。
- 支付页面名称或“支付密码”输入框不代表已接入真实支付。支付、物流、收货、退款和售后不属于当前完整能力。
- 本版本仅描述桌面网页；现有窄窗口样式不构成手机、平板适配承诺。

## 4. 内置 AI 助手

### 4.1 首页搜索助手

- 输入自然语言商品需求，展示识别摘要、相关商品、规格、库存和澄清问题；结果可继续分页。
- 支持多轮追加条件、修改预算、明确撤销旧条件、数值槽位补全和切换新需求。
- 搜索入口只消费搜索决策；查询任务进度、分析当前商品评论和确认/取消交易由购物对话入口承担。
- 右侧有有效短链时，在搜索助手上方单独展示短链列表，支持复制、打开和删除。
- 当前页面实际呈现为固定占位面板；没有把小精灵收起、拖动等未实现交互列为现有能力。

### 4.2 统一意图识别

处理顺序为：精确命令 → 可信上下文规则 → 唯一目录主体 → 一次模型解析动作与本轮条件。

- 确定性规则命中时不调用意图模型；不存在独立轻量分类阶段。
- 模型输出动作与置信度；仅新搜索和补充搜索提取本轮商品条件，其余动作使用独立业务分支。
- 搜索条件包括商品词、品类、品牌、预算、评分、库存、必需条件、偏好、数值规格、排除项和购买件数。
- 新搜索不继承旧条件；补充搜索由服务端合并历史，未提及不等于撤销；明确撤销使用带本轮原话依据的编辑。
- 数值规格检查比较符、数值、单位和原话证据；同属性另一侧边界保留，矛盾预算或规格区间进入澄清。
- 动作/置信度缺失及已返回字段类型、范围非法时不得默认为高置信度搜索；模型不可用时澄清。
- 搜索准入置信度至少0.8；候选接受仅由可信上下文规则放行，模型选品分类只给引导。
- “一次解析”指一个模型解析阶段，保留原LLM失败重试；评论分析自身的模型调用另计。

### 4.3 购物对话与任务

| 编号 | 功能 | 当前规则与边界 |
| --- | --- | --- |
| U-01 | 单一自动流程 | 对话购物只有一条自动流程，删除模式选择、请求参数、运行时字段及分支，不保留独立模型建单路径。 |
| U-02 | 数量传递 | 未明确数量默认 1 件；明确数量必须核实并贯穿库存、报价、订单和短链。 |
| U-03 | 搜索与选品 | 在真实同类商品中优先选完全符合要求的有货商品；无完全匹配时返回服务端推荐排序最高的替代商品。 |
| U-04 | 差异核实 | 预算、品牌、评分、数值规格、自然语言条件和排除条件有差异或无法核实时逐项说明；不能把未知描述为符合。 |
| U-05 | 有差异先确认 | 有差异时先生成有效报价，展示商品、数量、差异和费用；输入框上方显示确认/取消行，用户接受即直接提交。 |
| U-06 | 无差异自动提交 | 无差异时沿用报价后约 3 秒自动提交窗口；窗口内可取消，提交开始后禁止取消。 |
| U-07 | 精确命令确认 | 「帮我下单」「确认下单」「就这款」等精确命令与按钮等效，都校验当前任务和报价；模型分类本身不授权交易。 |
| U-08 | 取消与短链 | 取消后按已选商品及数量生成短链；库存不足等失败说明原因；断连或未知结果恢复原任务，不重复建单。 |
| U-09 | 优惠 C 资格 | 仅当前 AI 对话建立且服务端绑定的任务（含中途确认差异）享有 C；独立 AI 购物车来源或网页/短链提交不产生资格。 |
| U-10 | 不提供真实支付 | 不提供真实支付、扣款、物流或售后；「确认下单」不写成已实际支付。 |
| U-11 | 状态查询与恢复 | 取消周期轮询，正常操作消费接口返回结果；页面恢复和断连时按需查询，可手动刷新进度。 |
| AI-08 | 评论分析 | 围绕当前商品读取评论并归纳优点、缺点和分歧，显示读取/分析数量、完整性和原文引用；支持复用、续读和明确刷新。 |
| AI-09 | 评论暂停 | 分析评论时可暂停自动提交，恢复须走显式恢复动作；评论内容不能作为交易执行指令。 |

## 5. 库存、费用、订单与短链

### 5.1 库存和报价

- 可用库存按现有库存减预留量计算；购物车同步在事务内分配实际可用数量。
- 库存预留有效期为24小时；过期释放和重新同步按服务端逻辑执行，不保证页面显示的数量一直可买。
- 报价绑定购物车版本，期限取15分钟和当前预留期限的较小值；版本、预留或报价失效后需重新核验。
- 建单事务消费有效预留、扣减库存、保存订单及报价摘要；相同幂等请求复用结果，不同内容复用幂等键应被拒绝。
- 缺货项不产生额外应收；是否生成待补货订单和补货后自动建单尚未实现，规则为 needs_human_review。

### 5.2 当前计价实现

| 规则 | 代码行为 |
| --- | --- |
| A | 折前商品小计满NT$1,000，减NT$100。 |
| B | 折前商品小计满NT$990免运，否则运费NT$100。 |
| C | 仅当前 AI 对话建立且服务端绑定的购物任务（含中途确认差异）享有商品金额减免5%，不折运费；独立 AI 购物车来源或网页/短链提交不因此获得资格。 |
| 合计 | 商品小计 − A减免 − C减免 ＋ 运费；费用由后端统一计算。 |

### 5.3 订单展示

- 本人订单卡显示来源、编号、时间、商品名称、SKU、数量、商品行金额、总额，以及可展开的小计、优惠和运费。
- 名称读取创建时保存的快照；缺少历史快照时显示“历史商品名称未记录”，不冒用当前目录名称。
- 当前订单快照不等同于完整商品描述、图片和全部规格的历史版本。
- 订单创建不表示支付成功、发货、签收或退款完成。

### 5.4 交接短链

- 登录用户可为一个商品及1–99件生成短链；链接无时间TTL，支持创建人主动删除，成功交接建单后按当前逻辑消费失效。
- 持有令牌可匿名查看创建人显示名、商品和数量；展示当前商品资料，链接本身不承诺锁价或锁库。
- 当前 /handoff 存在匿名提交入口，以令牌对应创建人为业务身份，重新核验AI购物车、库存、报价和现有建单授权。
- 页面虽有“支付密码”，代码只检查非空和长度，未接入独立支付密码认证或支付渠道；这不是已完成的付款能力。
- 短链持有者的建单权限、凭证规则、隐私披露、“永久”含义及消费后失败恢复边界均为 needs_human_review。
